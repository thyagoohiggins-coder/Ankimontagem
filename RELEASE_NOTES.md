## Montador de Flashcards 3.1 — Windows e Android

Baixe em **Assets**:
- **MontadorDeFlashcards-android-x.y.z.apk**: app para Android. Abra no celular e permita a instalação.
- **MontadorDeFlashcards-Setup-x.y.z.exe**: instalador para Windows.
- **MontadorDeFlashcards-portatil-x.y.z.exe**: versão portátil para Windows, abre sem instalar.

### Novidade da 3.1 (Android)
- **Escolher o baralho antes de mandar para o Anki:** em ☰ → *Enviar para o Anki* aparece a lista dos seus
  baralhos do **AnkiDroid** para tocar e escolher (o AnkiDroid pede permissão uma vez), além dos baralhos usados
  antes. Também dá para digitar um baralho novo. Escolhendo um baralho do AnkiDroid, os cards entram exatamente nele.

### Da 3.0
- App Android com os mesmos recursos do Windows, `.apkg` para o AnkiDroid e backup compatível com o Windows.

> Android: antes de atualizar, faça ☰ → Exportar backup. Se a versão nova não instalar por cima, desinstale
> a antiga, instale a nova e importe o backup.
> Windows: se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
