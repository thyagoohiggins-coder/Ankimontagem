## Montador de Flashcards 3.0 — Windows e Android

Baixe em **Assets**:
- **MontadorDeFlashcards-Setup-x.y.z.exe**: instalador para Windows.
- **MontadorDeFlashcards-portatil-x.y.z.exe**: versão portátil para Windows, abre sem instalar.
- **MontadorDeFlashcards-android-x.y.z.apk**: app para Android. Abra no celular e permita a instalação.

### Novidade: app Android
- Os mesmos recursos do Windows, com interface para toque: linha do tempo ou grade de 2 colunas, destacar
  trechos, **🔗 Juntar** estruturas separadas (ex.: *got … back*), contagens, resumo e estudo do último sub-card
  até a raiz.
- Barra de formatação embaixo, acima do teclado: negrito, itálico, sublinhado, tachado, cor da fonte,
  cor do sublinhado, tamanho e limpar. A última formatação escolhida fica lembrada; colar sem formatação.
- Toque num trecho vermelho → **↪ Abrir sub-card**: painel com o caminho (`initiatives → problems → thing`),
  **▲ Card pai** e links para os sub-cards.
- **Enviar para o Anki**: gera o `.apkg` no celular e abre direto no **AnkiDroid**, com as mesmas cores,
  tamanhos e ordem do Windows. Importar o mesmo card do Windows e do Android atualiza a mesma nota.
- **Backup** no mesmo formato do Windows, para passar os cards de um para o outro.

### Windows (desde a 2.7)
- Fonte no Anki do tamanho dos outros cards do baralho; envio para baralho existente; sublinhado fino.

> Windows: o programa não tem assinatura digital. Se aparecer "O Windows protegeu o computador",
> clique em **Mais informações → Executar assim mesmo**.
> Android: antes de atualizar, faça ☰ → Exportar backup. Se a versão nova não instalar por cima, desinstale
> a antiga, instale a nova e importe o backup.
