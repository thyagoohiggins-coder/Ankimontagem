## Montador de Flashcards — programa nativo para Windows

Baixe em **Assets**:
- **MontadorDeFlashcards-Setup-x.y.z.exe**: instalador (menu Iniciar e atalho na área de trabalho).
- **MontadorDeFlashcards-portatil-x.y.z.exe**: versão portátil, abre sem instalar.

### Novidades da 2.7 (Anki)
- **Fonte do tamanho dos outros cards:** os tamanhos vão relativos ao texto normal do Anki, em vez de pontos fixos
  pequenos. Na janela *Enviar para o Anki* há o campo **Tamanho do texto normal no Anki**; com o Anki aberto
  (AnkiConnect), o programa usa sozinho o mesmo tamanho dos outros cards do baralho escolhido.
  O que você aumentou ou diminuiu no programa fica proporcional.
- O sublinhado vermelho acompanha o tamanho do texto; o card fica centralizado como os cards normais do Anki.

**Cards já enviados:** reenvie pelo AnkiConnect ou importe o `.apkg` de novo para atualizar.

> O programa não tem assinatura digital. Se o Windows mostrar "O Windows protegeu o computador",
> clique em **Mais informações → Executar assim mesmo**.
