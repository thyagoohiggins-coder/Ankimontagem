## Montador de Flashcards — programa nativo para Windows

Baixe em **Assets**:
- **MontadorDeFlashcards-Setup-x.y.z.exe**: instalador (menu Iniciar e atalho na área de trabalho).
- **MontadorDeFlashcards-portatil-x.y.z.exe**: versão portátil, abre sem instalar.

### Novidades da 2.6 (Anki)
- **Sublinhado do trecho destacado corrigido:** a linha agora fica colada à palavra, fina e vermelha, com todo o
  estilo dentro do próprio card. Funciona mesmo se o card estiver num tipo de nota diferente (ex.: Básico).
- **Enviar para um baralho que já existe:** a janela *Enviar para o Anki* lista os seus baralhos (pelo AnkiConnect,
  botão ↻) e lembra o último usado. Também dá para digitar um nome novo. No `.apkg`, o nome de um baralho
  existente faz os cards entrarem nele.

**Cards já importados antes:** reenvie pelo AnkiConnect ou importe o `.apkg` novo para atualizar o visual.

> O programa não tem assinatura digital. Se o Windows mostrar "O Windows protegeu o computador",
> clique em **Mais informações → Executar assim mesmo**.
